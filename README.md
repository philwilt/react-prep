# Prep React 19 Starter

Lightweight React 19 + Vite starter with a components/hooks layout and CSS Modules.

## Scripts

- `npm install` to pull dependencies.
- `npm run dev` to start the Vite dev server.
- `npm run build` to create a production build.
- `npm run preview` to preview the production build locally.

## Structure

- `src/App.jsx` entry component.
- `src/components/*` reusable UI pieces with module styles.
- `src/hooks/*` custom hooks.
- `src/utils/*` small helpers.

Everything is ready for JSX-first development; drop in your own routes, state, and API logic.
